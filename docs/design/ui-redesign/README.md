# Daily Organizer — макеты Full HD

Принятые пользователем референсы для реализации редизайна, 20 октября 2026 года. В комплекте 36 изображений: 17 основных экранов и сценариев плюс служебный лист состояний, светлая и тёмная темы. Каждый макет — 1920 × 1080. Адаптация отложена.

## Что находится в папке

- [exports/](exports/) — итоговые изображения.
- [references/](references/) — логотип, версии с названием и исходные референсы «Сегодня».
- [index.html](index.html) — альбом с выбором экрана, сравнением тем, скачиванием и масштабом 1:1.
- [mockup.html](mockup.html), [mockup.css](mockup.css), [mockup.js](mockup.js) — редактируемые исходники статических макетов. Цвета, шрифты и размеры заданы в CSS.

## Как посмотреть

Получите эту ветку репозитория и откройте `docs/design/ui-redesign/index.html` локально. На GitHub HTML отображается как исходный текст. Отдельный макет открывается как `mockup.html?screen=planning&theme=dark`; идентификаторы экранов есть в исходнике альбома. Для сетки используйте масштаб браузера 100%.

## Основные решения

- Верхняя навигация, компактные строки и раскрытие задачи внутри списка; обе темы имеют одну компоновку.
- В задачах вкладки «Активные / Выполненные / Все». Старый план — группа «Ранее» с точной датой; истёкший дедлайн отмечается отдельно.
- Календарь фильтров постоянно виден. День и период выбираются в нём, дублирующего списка дат нет. Панель одинакова в обоих состояниях.
- Формы задач компактные; план и дедлайн расположены рядом. У нового проекта редактируются этапы и явно выбирается завершающий этап с сохранением действующих ограничений.
- Подсказки проектов находятся у нижнего края страницы. Элементы управления календарём выровнены по высоте 50 px.
- «Справочник состояний» — примеры пустого списка, загрузки, ошибки и подтверждений внутри обычных страниц, а не отдельный раздел приложения.

Данные вымышлены. Исходный Today имеет размер 1586 × 992; финальные макеты адаптированы к Full HD. Исходники являются дизайн-артефактом: работа с API, сохранение и DnD относятся к реализации приложения.

# Аудит возможностей Daily Organizer

Исследовательские проходы выполнены 19 и 20 октября 2026 года на запущенном пользователем приложении `http://localhost:5173`. Использовались отдельные аккаунты с вымышленными данными; существующие личные записи пользователя не редактировались. Код приложения, API, БД и настройки запуска не менялись. Необратимое удаление не выполнялось: диалоги просмотрены и отменены.

Этот реестр описывает фактические возможности, которые надо сохранить при реализации дизайна. Он не является функциональным регрессом #38. Наблюдения первого прохода и его скриншоты остаются в [историческом снимке Git](https://github.com/SergeyMotynga/daily_organizer/tree/785497829151999cfaf2ff33bced48d52250c458/docs/design/ui-redesign/evidence); они не являются актуальными визуальными референсами.

## Страницы и соответствие макетам

| Поверхность | Существующий маршрут | Макет / сценарий |
|---|---|---|
| Вход | `/login` | `login`: логин, пароль, показать пароль, сохранение сессии, ошибка/загрузка |
| Регистрация | `/register` | `register`: имя, логин, пароль и повтор, валидация, успешная регистрация и переход ко входу |
| Сегодня | `/app/tasks/today` | `today`: план дня, выполненные, входящие, дедлайны, просрочка, создание и детали задач |
| Планирование | `/app/tasks/planning` | `planning`, `date-filters`: поиск, статусы, быстрые даты/день/период, сортировка, пагинация |
| Неделя | `/app/tasks/calendar?view=week` | `calendar-week`: предыдущая/следующая неделя, сегодня, переход к дате, выбранный день, план/дедлайн/повторения |
| Месяц | `/app/tasks/calendar?view=month` | `calendar-month`: соседние месяцы, задачи дня, скрытые строки «ещё» |
| Архив задач | `/app/tasks/archive` | `archive`: поиск, сортировка, исторические даты, восстановление и подтверждение удаления |
| Проекты | `/app/projects` | `projects`, `projects-archived`: поиск, сортировка, прогресс, создание, открытие, восстановление |
| Доска | `/app/projects/:id/board` | `project-board`: этапы, карточки, перемещение, добавление задачи в этап, поиск и фильтры |
| Список проекта | `/app/projects/:id/list` | `project-list`: этап, план, дедлайн, обновление, выделение, массовые действия и пагинация |
| Создание/редактирование задач | Диалоги внутри разделов | `task-create`, `task-edit`, `task-recurrence` |
| Создание/настройки проекта | Диалоги внутри проектов | `project-create`, `project-settings` |
| Общие состояния | Внутри соответствующих страниц | `ui-states` — служебное приложение к макетам |

Старые `/app/today`, `/app/planning`, `/app/calendar`, `/app/archive` — redirects на канонические маршруты. У них нет отдельных экранов. В меню аккаунта просмотрен выход; отдельного глобального маршрута настроек в исследованной версии нет.

## Поля, действия и ограничения

| Область | Фактическая возможность |
|---|---|
| Задача | Название до 255 символов, описание, проект или отсутствие проекта, этап, выполнение, просмотр, редактирование, архив/восстановление, удаление |
| План | Отдельные плановая дата и время. В исходном UI есть быстрые варианты; в новом дизайне форма компактнее, а даты доступны в полях и фильтрах. |
| Дедлайн | Собственные дата и время, независимо от плана; время используется вместе с датой. Предупреждение «план позже дедлайна» само по себе не запрещает сохранение. |
| Повторение | Нет / ежедневно / по будням / еженедельно, интервал по дням или неделям, начало и необязательное окончание. У режима по будням нет отдельного интервала. |
| Выполнение повтора | Выполнение конкретной даты, а не закрытие всего правила. Произвольное выполнение будущих дат не вводится дизайном. Повторяющуюся задачу нельзя помещать в завершающий этап. |
| Проект и этап | Без проекта выбор этапа отключён. Стандартные этапы: Бэклог, К выполнению, В работе, На проверке, Готово. Названия и порядок изменяются, можно добавлять этапы. |
| Завершение и удаление этапов | Исследованное приложение использует завершающую колонку; её удаление недоступно. Удаление заполненных этапов также недоступно. Макет не меняет эти ограничения. |
| Массовые действия | Перенос выбранных задач в этап и отметка выполнения. Массовое архивирование не добавлено. |
| Удаление проекта | Проект и этапы удаляются, задачи сохраняются без проекта. Последствия должны быть видны до подтверждения. |
| Регистрация | Пароль 8–30 символов, латинские буквы и цифры, обязательны обе группы, без пробелов; повтор совпадает. Восстановление пароля, email и SSO не добавлены. |
| Новые предметные функции | Команды, роли, бюджет, приоритеты, теги, AI и подзадачи в этот редизайн не входят. |

## Подтверждённые действия и пределы проверки

В первом проходе созданы отдельный QA-аккаунт, два проекта, 14 задач; проверены добавление/порядок этапов, массовый перенос/завершение, обычная задача и occurrence, архив/восстановление. Во втором проходе созданы ещё один демонстрационный аккаунт, проект и две задачи; просмотрены основные страницы, создание и редактирование, повторения, настройки и архив. Пароли в репозитории отсутствуют. Повторно создавать тестовые данные для просмотра статического альбома не требуется.

Маршруты и формы сверялись с `frontend/src/app/routes.tsx`, `frontend/src/pages/`, `frontend/src/features/tasks/` и `frontend/src/features/projects/`. Существующий граф использовался как навигационная карта; эти источники были проверены напрямую. Новый каталог дизайна в исходном графе не индексирован, его описание основано на самих документах и изображениях, а не на предполагаемых связях.

Полный drag-and-drop, ошибки сети, истечение сессии, timezone, нативное время, клавиатурная доступность готового приложения и действия во всех пограничных состояниях требуют проверки при реализации и регрессе. Backend/frontend tests при упаковке документации не запускались. Согласованные UX-изменения и границы реализации перечислены в [DESIGN.md](DESIGN.md).

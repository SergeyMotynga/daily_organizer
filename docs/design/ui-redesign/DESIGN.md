# Направление UI · на согласование

Связанные задачи: [аудит и макеты #36](https://github.com/SergeyMotynga/daily_organizer/issues/36), [реализация #37](https://github.com/SergeyMotynga/daily_organizer/issues/37), [QA #38](https://github.com/SergeyMotynga/daily_organizer/issues/38).

Этот комплект развивает выбранные пользователем [светлый](references/approved-today-light.png) и [тёмный](references/approved-today-dark.png) референсы. Направление выбрано; весь новый комплект ещё ожидает окончательного согласования. [Черновик в Notion](https://app.notion.com/p/3fe678c73f4781df8599e58df97ed940) приватный и не заменяет принятое ТЗ.

## Визуальная система

Компактная верхняя навигация, тёплый фон, мягкие радиусы и выровненная сетка. Контент занимает основную площадь. Статистика встроена в заголовки, второстепенные сведения отделены спокойной поверхностью. Без крупных приветственных блоков, декоративных графиков, обилия отдельных карточек и цветных дат плана.

Высокие PNG для mobile — полные страницы и формы, а не требование поместить весь экран без прокрутки в один viewport. На 844 px по высоте часть содержимого закономерно находится ниже сгиба. Видимые области прокрутки доски/календаря могут показывать часть соседней колонки. При реализации фиксируется контейнер, страница целиком по горизонтали не прокручивается.

## Поведение по разделам

| Раздел | Предложение для #37 | Что сохраняется |
|---|---|---|
| Навигация | Today / задачи / календарь / проекты / архив сверху; активная вкладка с подложкой и линией | Те же канонические URL; «Задачи» ведёт на существующее планирование |
| Сегодня | Время слева, заголовок и проект рядом, выбранная задача раскрывается в строке; контекст справа | Состав Today, выполненные сегодня, входящие, срочность и переходы к фильтрам |
| Создание из Сегодня | Поле внизу — вход в существующую форму, можно перенести введённое название в неё | Обычные правила создания и валидации; новая отдельная бизнес-операция не требуется |
| Планирование | Компактная строка поиска/дат, быстрые фильтры и статусы, таблица | Все существующие пресеты, отдельные дата/период, сортировки, 10/20/50 на странице |
| Календарь | Неделя и месяц; выбранный день с планом, дедлайнами и повторением в метаданных | План и дедлайн одной задачи независимы; нет продолжительности задачи или нового hourly planner |
| Архив | Чёткие исторические даты; заметное восстановление и отдельное удаление | Архив не становится статусом выполнения |
| Проекты | Спокойные карточки с фактическим прогрессом; доска и список на одной глубине | Активные/архивные, поиск, все сортировки и восстановление |
| Доска | Мягкие колонки и компактные карточки; ручка перемещения и «Добавить задачу» | Пользовательские колонки, один завершающий этап, существующий DnD |
| Список проекта | Плотная таблица; выбранные строки и одна панель массовых действий | Выбор страницы/задач, перенос этапа, выполнение и пагинация |
| Мобильные списки | Те же данные в карточках: название, статус/этап, план, дедлайн и меню с историей | Табличные поля не теряются; массовые действия доступны и на телефоне |
| Формы | Группы «Проект», «Статус», «Когда делать», «Дедлайн», «Повторение» | Существующие обязательность и ограничения; план/дедлайн не объединяются |
| Детали | Из Сегодня — inline; из других разделов — правая панель; на телефоне полноширинная форма | Описание, свойства, даты создания/обновления/архива и все действия. Дополнительная история доступна через детали |
| Повторение | Отдельное поле правила и условные поля интервала/начала/окончания | Daily, weekdays, weekly. Выполнение сегодня не закрывает правило |
| Настройки проекта | Inline-переименование, стрелки и drag handle; завершающий этап явно отмечен | Добавление, порядок, назначение завершающей колонки, архив/восстановление, удаление проекта с сохранением задач |
| Авторизация | Компактные поля, ясные ошибки, отдельный успех регистрации | Вход по логину, показать пароль, сохранение сессии; текущие правила пароля |

В раскрытой строке Today находятся частые действия; редкие свойства и удаление доступны через меню деталей. Новый UI не должен лишать пользователя действий, показанных в текущей карточке задачи.

`task-occurrence` намеренно подписывает сегодняшнее выполнение. Переносы/исключения отдельных повторений, streaks и новые массовые действия не добавляются. Выбор другой календарной даты не даёт оснований молча менять дату выполнения в API.

## Состояния и доступность

- Для полей: default, focus, disabled, invalid; подпись постоянная, ошибка рядом. В `task-no-project` выбор этапа отключён с объяснением.
- Для отправки: pending с защитой от повторного запроса; success; понятная ошибка с повтором. Введённый текст после ошибки сохраняется.
- Для списков: загрузка, нет данных, нет совпадений, ошибка; пустой результат поиска отличим от первого запуска.
- Для архива и удаления: восстановление сохраняет статус; необратимое удаление имеет явное подтверждение. Удаление проекта объясняет судьбу задач.
- Для повторений: выполнено сегодня и отмена сегодняшнего выполнения; отдельный лист с четырьмя правилами и условными полями.
- При реализации: семантические кнопки/поля, видимый focus ring 2 px с offset 3 px, клавиатурное управление, названия icon-only действий, `aria-live` для результатов, возврат фокуса после закрытия формы.
- DnD не является единственным способом управления этапами: сохраняются стрелки колонок и массовый перенос задач.
- Учитывать reduced motion; анимация не обязательна для понимания состояния. Новые библиотеки ради макета не добавляются.

Проверены десять основных текстовых пар палитры: контраст 5.18:1–15.86:1, все выше 4.5:1. Это проверка токенов, а не заявление о WCAG-сертификации будущей реализации. Hit targets, screen reader, клавиатуру, intermediate breakpoints и реальные состояния сети требуется проверить в #38.

Минимальный рабочий размер знака 24 px, 16 px показан как предельная проверка. Охранное поле не меньше четверти высоты знака. Пропорции, расстояния между частями и толщину линии не менять. Для нового названия потребуется обновить только wordmark; знак независим от него.

## Статус материалов

`renders/*.svg` — редактируемые векторные макеты, `*.png` — нативные растровые превью того же описания. Это не скриншоты новой работающей версии. Браузерный просмотр локального альбома инструментом не подтвердился: HTTP-предпросмотр не открылся, файловый URL запрещён политикой браузера. Визуальная проверка выполнена по PNG и обзорным листам, SVG разобраны XML-парсером, ссылки альбома проверены локально.

Материалы готовы к просмотру пользователем. Утверждение всех UX-решений и перенос их в принятое ТЗ остаются после согласования. Приватный черновик Notion можно перенести в хаб проекта после выбора места пользователем.

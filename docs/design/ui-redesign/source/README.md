# Исходники статических макетов

Эти инструменты создают только дизайн-артефакты. Они не запускают приложение, не подключаются к API и не меняют QA-данные.

| Файл | Назначение |
|---|---|
| `render_mockups.py` | Реестр 39 состояний, компоненты и раскладка SVG; запись manifest с SHA-256 |
| `outline.ps1` | Arial → настоящие SVG-контуры через Windows WPF |
| `outline-logo.ps1` | Контурная надпись четырёх standalone-версий логотипа |
| `rasterize.cjs` | Окончательный SVG → PNG через Sharp; превью логотипа |
| `proof_sheets.py` | Обзорные листы и сравнение с эталоном, без изменения исходных референсов |
| `validate.py` | Контуры, ссылки на них, хеши, размеры, ссылки альбома, текстовые границы/наложения и контраст |

Для пересборки нужны Windows с Arial/WPF, Python с Pillow и Node.js с Sharp. В рабочей среде использованы уже доступные библиотеки; зависимости приложения не изменены. Для просмотра готового альбома эти инструменты не нужны.

Из папки `docs/design/ui-redesign/`, с доступными `python`, `node` и Sharp в Node resolution path:

```powershell
python source/render_mockups.py
python source/validate.py
```

Если нужно заново сформировать надпись логотипа:

```powershell
powershell -NoProfile -File source/outline-logo.ps1
node source/rasterize.cjs renders
```

Промежуточные данные `staging/` исключены из Git. В SVG хранятся контуры, поэтому прямое редактирование надписи как текста не предусмотрено: текст меняется в генераторе. Метаданные `data-text` сохраняют смысл надписей для поиска и проверки.

`validate.py` не является браузерным или функциональным тестом приложения. Упрощённые прямоугольники текста не доказывают отсутствие всех визуальных дефектов; итоговое согласование остаётся за пользователем. Обзорные PNG и сравнение служат материалом ручной сверки и не используются для изменения исходных референсов.

## Просмотр

Скачайте или получите эту ветку репозитория и откройте `docs/design/ui-redesign/index.html` локально. Для просмотра через локальный сервер из корня репозитория:

```powershell
python -m http.server 8871 --bind 127.0.0.1 --directory docs/design/ui-redesign
```

Откройте `http://127.0.0.1:8871/`. Для отдельного статического макета: `mockup.html?screen=planning&theme=dark`. Все идентификаторы перечислены в `catalog.json`; темы — `light` и `dark`. Сетка рассчитана на Full HD и масштаб браузера 100%. В альбоме изображения можно вписать в окно или рассмотреть 1:1.

HTML/CSS/JS здесь — исходники дизайн-артефакта. Они не обращаются к API, не изменяют приложение и не реализуют сохранение, фильтрацию или перетаскивание. В самом альбоме работают выбор страницы, темы, просмотр крупно и скачивание изображений.

## Статус и использование

- Этот каталог — актуальный источник визуальных референсов. Старые SVG/PNG и мобильные варианты из прежнего альбома удалены из текущего содержимого ветки; история Git сохраняет их.
- Адаптация под другие разрешения отложена пользователем. Исходный Today в `references/` имеет размер 1586 × 992; итоговые макеты адаптированы к 1920 × 1080. Пиксельная идентичность исходному растру не заявляется.
- «Справочник состояний» — приложение к макетам, а не новая страница продукта. Его элементы используются внутри обычных экранов.
- Реализация — [Issue № 37](https://github.com/SergeyMotynga/daily_organizer/issues/37), функциональный регресс — [№ 38](https://github.com/SergeyMotynga/daily_organizer/issues/38). Публикация альбома в облаке не входит в этот PR.
- [Issue № 36](https://github.com/SergeyMotynga/daily_organizer/issues/36) и [draft PR № 39](https://github.com/SergeyMotynga/daily_organizer/pull/39) фиксируют результат. До слияния Issue остаётся открытой.
- Продуктовые требования ведутся в Notion. Согласованные UX-решения перечислены в DESIGN.md для переноса перед реализацией; этот PR не меняет страницы Notion и API.

## Проверка комплекта

Из этого каталога выполните `python verify.py` в среде с Pillow. Валидатор проверяет изображения, хеши manifest, парность тем, сохранённые измерения, контраст выбранных пар, токены и локальные ссылки. Он не заменяет браузерный просмотр и тестирование приложения.
